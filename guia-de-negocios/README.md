# Guia de Negócios do Conecta

Site público com todos os nucleados, organizados por categoria, com Instagram,
WhatsApp e site de cada um.

- **No ar:** https://guiaconecta.netlify.app
- **Arquivo:** `index.html` (página única, sem build, fotos e fonte embutidas)
- **Origem:** repositório SistemaKA, pasta `conecta/` (branch
  `claude/conecta-repository-7h00xx`, commit `a50207c`, ago/2026). Esta é uma
  cópia da versão publicada.
- **Netlify:** projeto `guiaconecta`.

Edite `index.html` aqui (adicionar/remover nucleado, trocar link). Para
publicar a partir deste repositório, aponte o projeto `guiaconecta` da Netlify
para este repo com **Base directory = `guia-de-negocios`**.
